# VICE TRACKER

Tracker visual de GTA VI: vehículos, animales y cartas coleccionables.

Incluye perfiles independientes de Ruru, Duque, Coco y Rays, comparador entre jugadores, búsqueda, filtros y progreso guardado en el navegador.

## Uso

Abre `index.html` en un navegador o utiliza GitHub Pages cuando esté activado.

**Nota:** el progreso se almacena localmente en cada navegador (`localStorage`); publicar la web no sincroniza los datos entre dispositivos ni importa automáticamente las marcas de archivos HTML locales.

Proyecto de fans, no afiliado a Rockstar Games.
